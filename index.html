Release projection

Load a Jira CSV export of one fix version to see when it is likely to finish. Everything runs in your browser; the file is never uploaded.

Drop a Jira CSV export here or use “Choose CSV…”.

Best results: in Jira search for fixVersion = "Your Version", then Export → Export CSV (all fields). A “current fields” export also works if the columns include Resolved and either Story Points or Original estimate.

    How each projection works
    Linear regression
    A least-squares straight line through cumulative completed work for each day in the fit window, extended until it reaches today's total scope.
    Linear + scope growth
    Also fits a line to total scope over time and finds where the two lines cross. This is the realistic date if tickets keep being added at the same rate.
    Polynomial regression
    A quadratic or cubic least-squares curve through the same points. It captures acceleration or slowdown, but it can swing a lot on little data. If the curve flattens before reaching scope, there is no date.
    Average velocity
    Remaining work ÷ the mean amount completed per full week in the fit window.
    Optimistic / pessimistic bounds
    Optimistic: every remaining ticket is one Fibonacci step smaller than its estimate (5 → 3), delivered at the fastest rolling-average velocity seen. Pessimistic: one step larger (5 → 8), at the slowest non-zero rolling velocity. For Original estimate, the ± uncertainty percentage is used instead of Fibonacci steps.
    Ticket rate
    Open tickets ÷ the mean number of tickets completed per week. This ignores estimates entirely, which makes it a useful cross-check.
    Monte Carlo
    Picks random past full weeks (with replacement) and plays them forward until remaining work hits zero, 5,000 times. P50 means half of the simulated futures finished by that date; P85 is a common commitment date.
    Caveats
    In-progress tickets count as fully remaining. Tickets created before the release start count as initial scope. Weekly figures use calendar weeks starting on Monday, so holidays and time off show up as slow weeks.
